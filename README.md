# Data Engineering Bootcamp

A 20-week hands-on journey into Data Engineering, focused on building practical skills through real-world projects, data pipelines, and production-oriented practices.

## 🎯 Goal

The goal of this project is to build a strong, practical foundation in Data Engineering by progressing from core programming and database concepts to complete data pipelines and production-oriented systems.

The project combines structured learning with hands-on implementation, documentation, testing, and engineering best practices.

## 🗺️ 20-Week Roadmap

| Phase                   | Weeks | Focus                                                                   |
| ----------------------- | ----: | ----------------------------------------------------------------------- |
| Foundations             |   1–4 | Python, Linux, Git, SQL and data fundamentals                           |
| Data & Databases        |   5–8 | Relational databases, data modeling and advanced SQL                    |
| Data Pipelines          |  9–12 | ETL/ELT, APIs, batch processing and pipeline design                     |
| Orchestration & Quality | 13–16 | Workflow orchestration, testing, data quality and monitoring            |
| Production & Cloud      | 17–20 | Docker, cloud concepts, deployment and production-oriented architecture |

> The roadmap is a flexible guide and may evolve as the project progresses and practical requirements become clearer.

## 🎓 Learning Approach

This is not intended to be a collection of tutorials or isolated exercises.

The focus is on:

* Understanding the fundamentals
* Writing practical code
* Building complete projects
* Working with real-world data
* Designing maintainable pipelines
* Testing and validating data
* Documenting technical decisions
* Using Git and GitHub professionally
* Gradually adopting production-oriented engineering practices
